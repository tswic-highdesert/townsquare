# TownSquare design

## Approved visual baseline

**[The Daily design system](system/README.md)** — locked by Tal on 2026-09-10, version 1.0.0. Use it for new visual work. [Tokens](system/tokens.json) and approved font reference assets live beside the rules.

The system retains the existing TownSquare mark and wordmark, uses Nunito Sans and Phosphor, and combines softer geometry with compact, useful layouts. Do not restart broad style exploration in routine implementation work.

## Source-of-truth order

1. Product, identity, permissions, sandbox, and data-honesty contracts in the root specifications.
2. `system/` for the approved visual language and component rules.
3. `hifi/` and `hifi-v2/` for existing screen inventory, behavioral requirements, and historical visual reference. Their older visual language is superseded where it conflicts with `system/`.

The approval is a design decision, not a production rollout. Existing unrelated working-tree changes are unaffected.
